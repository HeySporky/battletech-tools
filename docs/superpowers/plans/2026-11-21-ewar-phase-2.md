# E-War Phase 2 (Stealth and Sensors) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stealth armor, Null-Signature, Void-Signature, Chameleon LPS, Mimetic and BA stealth, ECM and ECCM modes (Guardian, Clan, Angel, Watchdog, Nova CEWS, BA/infantry ECM), ghost targets and every active probe (Beagle, Bloodhound, Clan, Light, Watchdog, Nova) change to-hit, cluster shifts, notes and detection results in roster play, each as the governing edition's book prints it, every modifier shown with a label.

**Architecture:** Extend `src/utils/ewar-play.ts` and the `IEWarItemRule` table in `src/data/rules-editions.ts` (no new source file). `IEWarPlayState.stealthOn` (one boolean) is split first into a per-system map, with old saves migrated on load. Stealth numbers for the unit's own attacks come from target ticks (the enemy has no unit object); the unit's own stealth shows as "+N to attacks against this unit" because the app cannot roll the enemy's attack. ECM state is worked out per line of fire from ECM and ECCM counts instead of the Phase 1 hostile-ECM boolean alone (the boolean stays as a manual override).

**Tech Stack:** TypeScript, React 18, Vitest (PowerShell only).

**Spec:** `docs/superpowers/specs/2026-11-20-ewar-play-design.md` (Design 1-4, Calls 1, 2, 3, 5, 6; Appendix A "ECM, ECCM and probes" and "Stealth"). Phase 0 plan `2026-11-20-ewar-phase-0.md`, Phase 1 plan `2026-11-21-ewar-phase-1.md`. Issue #642.

## Review Focus

1. Null-Signature plus Chameleon both on: modifiers stack (TO:AUE p.148, p.112); Chameleon with Void-Signature or Stealth Armor: refused with a label (Task 3).
2. Stealth armor on and the unit's ECM: switched off in TW 4th printing on, BMM, CRB; keeps working with enemy-ECM effects in BMR(R) and TW 1st/3rd printings (Task 4).
3. Equal or more friendly ECCM than hostile ECM on a hex: ECM does not work; Angel counts as two, and Angel ECM is beaten only by Angel ECCM (Task 4).
4. A destroyed stealth system, probe or ECM suite: no effect though `getEWarGear()` still lists it (Tasks 3, 4, 5).
5. An edition with no entry (BD, BT2, BTM, BT3, BT4, BTC for stealth, CBT box): nothing applies and the label names the edition (Tasks 1, 3).
