# E-War Phase 1 (Missiles) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AMS, Laser AMS, APDS, Artemis IV/V/prototype, Apollo, Narc, iNarc pods, TAG, Light TAG and semi-guided ammo change the to-hit number, the Cluster Hits roll and the take-damage dialog in roster play, each as the governing edition's book prints it, with ECM cancelling the ones it cancels, and every modifier shown with a label.

**Architecture:** Fill the three Phase 0 stubs in `src/utils/ewar-play.ts` (`getEWarToHit`, `getEWarClusterShift`, plus a new `getEWarDefense`) from per-edition numbers held in `IEWarItemRule` (`src/data/rules-editions.ts`). The 'Mech view feeds them through `getTargetToHitFromWeapon` and its Target dialog cluster buttons; other views get the to-hit and shift as labelled lines, as `getQuirkToHit` reaches them today. No new source file.

**Tech Stack:** TypeScript, React 18, Vitest (PowerShell only).

**Spec:** `docs/superpowers/specs/2026-11-20-ewar-play-design.md` (Design 1-4, Calls 1, 2, 3, 5; Appendix A "Missiles and defenses"). Phase 0 plan: `2026-11-20-ewar-phase-0.md`. Issue #642.

## Global Constraints

- Every rules edition, every unit type, every time (memory every-edition-every-rule.md). The attacker's edition governs its attack; the defender's governs its own defenses; an item the governing edition lacks has no effect, with a label saying so (Call 2).
- Condense and extend: no new source file; tests join `src/utils/ewar-play.test.ts`, `src/data/rules-editions.test.ts` and the existing view/class tests.
- Every number is read from the book's page image, never memory or OCR text (`py -3.11 -I library_search.py "<words>" --books`, `render_page.py` from `C:/repo/ResourceLibrary`); a garbled extract page is rewritten in `text/<book>.txt` and logged in `text/_corrected_pages.md`, CRLF kept; every page image pulled goes back WHOLE into every printing's extract, pushed. The Appendix A rows are the starting point, not a substitute for the image where a number is not already quoted there.
- Saves: new state optional in every export shape; old saves load unchanged.
- Vitest: `npx vitest run --project unit <path>` in PowerShell. `npm run check` before deploy.
- Commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` (or the model that did the work).

## Review Focus

1. Artemis IV with a Streak, Narc-equipped, Swarm or Thunder ammo, or indirect LRM fire: no shift, labelled "not with X" (Task 2).
2. Hostile ECM on the line of fire: Artemis IV/V, Narc and semi-guided effects cancelled where the edition says so, kept where it does not (BTC: ECM nullifies Artemis and Narc; BMR on Narc only; Angel blocks Streak lock) (Task 2).
3. Cluster size 2 with a +2 shift, and a roll pushed past 12 (Artemis V +3, maximum 12): clamped to the table (Task 2).
4. A destroyed Artemis/AMS/TAG item: no effect, even though `getEWarGear()` still lists it (Task 2, Task 4).
5. An edition with no `ewarPlayRules` entry for the item (BT2, BTM, BT3, BT4, Battledroids): nothing applies and the label says the edition does not have it (Task 1, Task 2).
