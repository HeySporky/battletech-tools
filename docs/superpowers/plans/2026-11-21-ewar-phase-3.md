# E-War Phase 3 (C3 Networks and the Rest) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every C3 type (Master/Slave, C3i, Boosted, Emergency Master, Remote Sensor, Naval C3, Nova link, battle armor C3), EW Equipment, communications equipment, ghost targets and aerospace ECM change roster play, each as the governing edition's book prints it: network records with roles and limits, C3 range from the nearest networked unit, ECM and stealth cutting a unit off, with every modifier labelled.

**Architecture:** Extend `src/utils/ewar-play.ts` and the `IEWarItemRule` table in `src/data/rules-editions.ts` (no new source file). `BattleMechForce.c3Networks` (uuid -> name) becomes derived from stored network records; old saves load unchanged and Battle Value keeps reading the same map. C3 effects reach a unit's own attacks through one new target tick (the range from the nearest networked unit) and one cut-off decision per unit; the unit's own network state shows in its E-War block.

**Tech Stack:** TypeScript, React 18, Vitest (PowerShell only).

**Spec:** `docs/superpowers/specs/2026-11-20-ewar-play-design.md` (Design 1-6, Calls 1-7, Appendix A "C3" and "ECM, ECCM and probes"). Earlier plans: `2026-11-20-ewar-phase-0.md`, `2026-11-21-ewar-phase-1.md`, `2026-11-21-ewar-phase-2.md`. Issue #642.

## Global Constraints

- Every rules edition, every unit type, every time (memory every-edition-every-rule.md). The attacker's edition governs its attack; an item the governing edition lacks has no effect, with a label naming the edition (Call 2). A later edition that drops an item keeps it as apocryphal (memory removed-items-stay-apocryphal.md); Maximum Tech items ride on BMR and BMR(R).
- Condense and extend: no new source file except tests named below; tests join `src/utils/ewar-play.test.ts`, `src/data/rules-editions.test.ts`, `src/classes/battlemech-force.test.ts` (or `battlemech-force-tech.test.ts`) and each view's existing test file.
- Apocryphal carry-forward (NGCFells, 2026-11-21; memory removed-items-stay-apocryphal.md): an item an earlier edition prints and a later one drops stays available in every later edition as `apocryphal: true`, playing by the last printing (book and page of that printing). Edition order for E-War rules: BTC, BTC:RoW, BMR, BMR(R), TW, BMM, CRB. Today only a TW -> BMM/CRB copy loop exists (`rules-editions.ts` ~1038); Task 1 generalizes it to the whole chain. Never delete an item from a later edition; the catalog `editions` lists keep it reachable.
- Every page image pulled, in any task: the whole page goes into every printing's extract and `text/_corrected_pages.md` in `C:/repo/ResourceLibrary` (CRLF kept, `put_page.py`), and ResourceLibrary is committed and pushed BEFORE the task's btt-rebuild commit. Each task's commit step is not done until `git -C C:/repo/ResourceLibrary status` is clean and pushed (or no image was pulled, said in the commit body).
- Check the ResourceLibrary extract FIRST; pull a page image only when the extract is missing, garbled or in doubt (`py -3.11 -I library_search.py "<words>" --books`, `render_page.py` from `C:/repo/ResourceLibrary`). Every page image pulled goes back WHOLE into every printing's extract and `text/_corrected_pages.md`, CRLF kept, pushed. Appendix A "C3" rows are the starting numbers.
- Saves: new state optional in every export shape; an old `c3Networks` map loads as one record per name with every member a Slave-or-C3i by its gear. Battle Value reads the same network membership as before.
- Vitest: `npx vitest run --project unit <path>` in PowerShell. `npm run check` before deploy. Bash heredocs with an apostrophe are blocked by the hook: write scripts with Write.
- Commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` (or the model that did the work).

## Review Focus

1. A Master destroyed, or its carrier lost: its portion (BTC to BMR(R)) or the whole network (TW, CRB) stops; Slaves keep no range sharing (Task 3).
2. A unit with stealth armor, Null-Sig, Void-Sig or Mimetic on is cut off; Chameleon LPS is not (CRB p.209); Boosted units refuse stealth armor too (Task 3).
3. A unit inside hostile ECM: cut off in TW, BMR(R), BMM; degraded +1/+2 in CRB; C3i, Boosted (except Angel) and Nova links per their rows; friendly ECCM cancels it (Task 3).
4. A network over the edition's limit (twelve, six C3i/Naval, three Slaves per Master pre-TW, one network per unit, Master mixed with C3i): refused on save with a label, never silently trimmed (Task 2).
5. Old saves with `c3Networks` only, and BV unchanged for them in every edition (Task 2).
6. An item a later edition drops (Emergency Master, Remote Sensor, EW Equipment, communications equipment, Naval C3 after TW; anything BMR prints that TW or BMR(R) lacks; anything BMM prints that CRB lacks): present in the later edition as apocryphal, playing by the last printing, with the label saying so (Tasks 1, 3, 5).
